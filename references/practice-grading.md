# 实操评分表

每题四项，每项 0–2 分。0 表示未完成或关键判断错误，1 表示方向正确但有遗漏，2 表示满足该项完整条件。引用用户实际交付物中的一个数字、判断或动作作为评分依据。对有理由的可行替代方案按同一要求给分。

## 运营与市场

| 评分项 | 拿到 2 分需要做到 |
| --- | --- |
| 有效报名率 | A 10.00%，B 16.67%，C 6.25%，分母均为各渠道点击数 |
| 单个有效报名成本 | A 20 元，B 12 元，C 20 元，比较时使用有效报名数 |
| 预算和行动 | 金额合计 600 元，最多两个渠道。说明为何优先测试 B 或为什么按已知约束给其他渠道一部分。没有把「点击最多」等同为「有效报名最好」 |
| 下一轮验证 | 写一个可持续记录的主指标，例如有效报名成本。说明未随机分组或人群差异导致这批数据无法证明渠道本身造成效果 |

可行示范为 B 480 元、A 120 元，记录各渠道的有效报名量和成本。给 A 保留小额对照属于下一轮测试安排。不要把现有平均成本当作新预算下的确定产出。

## 银行与综合职能

| 评分项 | 拿到 2 分需要做到 |
| --- | --- |
| 金额和缺件 | L02 的申请比凭证少 90 元，L03 缺凭证。没有将缺件金额当作零 |
| 重复凭证 | R04 同时出现在 L04 与 L05，两条都标待复核，保留原台账 |
| 分流结论 | 只有 L01 可继续常规复核流程。L02 至 L05 暂挂。没有在审核人确认前修改金额、认定某一条重复申请有效或承诺放行 |
| 沟通和取证 | 对 L02 核对申请人与原始票据。对 L03 催补凭证。对 L04、L05 要求两名申请方与复核人确认对应关系，注明再次核验动作 |

## 人力行政与项目支持

| 评分项 | 拿到 2 分需要做到 |
| --- | --- |
| 可执行排期 | 面试 14:00–14:30，协调会 15:00–15:30。保留 10:00 既有评审，结论 16:00 前同步 |
| 通知和负责人 | 周二 9:30 前通知候选人和甲确认面试。通知甲乙协调会改期，安排本人或经确认的负责人同步结论 |
| 倒排材料 | 17:00 前需要完整核对 60 分钟，所以财务表最晚 16:00 到手。提前向丙询问交付时间并安排检查点 |
| 异常处理 | 如确认超过 16:00，及时向报告负责人说明缺失项、影响、预计补齐时间和可先交的已核部分。标明待补数据，等负责人确认是否分批交付 |

评分末尾给一条优先改进动作和可直接重交的输出规格。成绩描述本次练习的表现。用户完成的内容如需用于作品集，标明「岗位模拟练习」。
