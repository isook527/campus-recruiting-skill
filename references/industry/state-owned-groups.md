# 央企、国企及大型集团校招

## 常见流程

集团或成员单位公告 → 网申与资格审查 → 测评或笔试 → 面试 → 背景、档案或其他材料核验 → 公示或录用通知 → 签约。是否有公示及其形式以本轮公告为准。

## 重点核对

- 集团、招聘单位、成员单位、签约单位和实际用工单位的关系
- 岗位工作地点、轮岗、派驻、基层锻炼和调动范围
- 专业目录、学历、政治面貌、证书等是硬门槛还是优先项
- 报名表、证明附件、盖章或学校材料要求
- 集团与成员单位之间是否限报、互斥或允许调剂
- 唯一报名渠道及第三方 ATS 是否由官方公告直接指向

## 准备动作

1. 从集团公告追到具体成员单位和岗位页，不凭集团品牌判断岗位。
2. 综合职能岗准备制度执行、文字材料、组织协调和数据台账的真实证据。
3. 笔试若含材料写作，练材料概括、对策和应用文。题型仍以邀请为准。
4. 所有「内推」「保录」「直签」说法回到公告和官方网申核验，收费时按高风险处理。

## 易混点

- 「集团校招」不等于与集团总部签约。
- 「备案」「人才库」「拟录用」「公示」是不同状态，不能合并为已录用。
- 「编制」「正式工」「市场化用工」等词必须要求本单位、本岗位的书面口径。

## 官方例证

- [中航集团管理储备生 2027 届招聘简章](https://zhaopin.airchina.com.cn/campus/jobs/2026/10/185602.shtml)：官方岗位页展示网申、资格审查、笔试、面试与录用结果公示等环节。核验时间 2026-11-09。
