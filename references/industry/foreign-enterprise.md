# 外企岗位轨道

「外企」不是统一岗位类型。先确认具体法人、业务、岗位语言、工作地点和招聘地区，再决定中文或英文材料。英文官网、英文岗位名或外资背景都不能自动推出必须全程英文。

## 重点核对

- 岗位所在法人、地区和实际工作语言
- 网申允许中文、英文还是双语简历；文件格式和大小
- 英语成绩、口语或其他语言是硬门槛还是工作偏好
- 在线测试的语言、题型、时限、有效期和重测规则
- 面试是中文、英文、双语、案例、录播还是多人面试
- 跨城市、跨境或工作资格要求

## 英文简历

1. 用英文重写事实，不逐字翻译中文套话。
2. 每条使用 `Action + Object + Method + Verifiable Deliverable`。
3. 公司、学校、专业和证书用可核官方英文名；没有官方名时保持一致并避免自创缩写。
4. 日期、时态、英式或美式拼写保持统一。
5. 数字、结果和职位级别仍遵守真实性边界。
6. 只有岗位或网申明确要求时才把照片、证件、成绩单等加入材料。

## 英文面试练习

- 30 秒：姓名、专业、目标岗位和一条最相关证据。
- 90 秒：按 `Situation → Task → Action → Result/Reflection` 回答经历题。
- 60 秒：解释 Why this role，用一条公司事实、一项岗位任务和一段本人证据连接。
- 追问：What exactly did you do? How did you measure it? What would you change?

不背诵生僻表达。先保证直接回答、事实准确和能承受追问，再优化语言。

## 在线测试

按 [测评、笔试与线上任务](../assessments.md) 核验邀请。语言、题型和时长以本岗位邀请为准；不使用代考、实时答案或规避监考工具。

## 官方例证

- [宝洁中国招聘流程](https://careers.pg.com.cn/cn/zh/hiring-process)展示申请、在线评估、行为与情景面试及录取步骤，并说明岗位会影响测评组合；核验时间 2026-11-09。
- [德勤中国校园招聘流程](https://www.deloitte.com/cn/en/careers/explore-your-fit/find-your-possible/our-recruitment-process)说明网申材料语言会因地区和岗位而不同，并展示在线测试与面试环节；核验时间 2026-11-09。

这些例证不构成其他外企的统一语言或流程要求。
