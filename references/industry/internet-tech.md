# 互联网与科技平台校招

## 常见流程

网申或内推登记 → 简历筛选 → 在线测评或笔试 → 一至多轮业务面试 → HR 沟通 → 录用与签约。产品、运营、市场和职能岗的顺序可能不同。没有本轮官方材料时只能称为常见流程。

## 重点核对

- 岗位 ID、招聘项目、城市和毕业窗口
- 最多投递数、志愿是否互斥、提交后能否修改
- 内推是否替代网申，推荐关系是否真正进入系统
- 是否滚动处理、是否有统一截止和时区
- 作品、案例、测评或在线作业是否必交
- 第三方 ATS、测评和视频平台是否由官方公告或邮件明确关联

## 准备动作

1. 从 JD 拆出三项核心任务，用真实项目说明本人动作、产物和复盘。
2. 准备一份与产品或业务有关的可验证案例。模拟作品明确标注，不冒充真实业绩。
3. 对业务面试练「结论 → 情境 → 本人动作 → 结果或反思」，避免只讲团队成果。
4. 收到测评或录播邀请后，按 [测评、笔试与线上任务](../assessments.md) 核域名、截止、次数和设备。

## 易混点

- 日常实习、暑期实习、转正实习和正式校招不是同一项目。
- 「提前批」「专项计划」「管培」的资格、流程和转正口径要看本轮公告。
- 经验帖中的题型、轮次和面试官风格只能作练习线索。

## 官方例证
