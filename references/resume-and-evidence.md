# 简历、证据与一分钟自我介绍

读目标岗位的三个关键动作，再到[本地证据卡](../templates/local-tracking.md#经历证据卡)逐条映射。每张卡只写一段真实经历。先问本人具体做了哪步、用了什么、交付物在哪。把用户确认与材料可证明分开。没有准确数字时先写做法和产出，把缺口单列。

简历句用「本人动作 + 任务对象 + 使用方法 + 可验证产出」。责任边界不清时给保守版，等证据后再增强。问到团队数字时先确认范围、来源和本人贡献，不能证实就删去数字。示范中提到的证据类型可作为查找线索；不需要为练习交出原件或他人联系方式。

## 五类证据示例

| 经历类型 | 已知事实示例 | 可练习方向 | 禁止添加 | 可寻找的证明材料 |
| --- | --- | --- | --- | --- |
| 餐饮兼职 | 点单、制作饮品、清理、应对高峰期顾客催促 | 服务流程、现场应对、按标准执行 | 不要擅自添加客流量、销售额或培训新人 | 排班记录、聊天记录、门店照片 |
| 市场调研课程项目 | 搭建问卷、投放、导出数据、剔除无效问卷、制作图表、写报告数据部分 | 问题拆解、数据整理、结果表达 | 没有样本数和结果数字就不要量化 | 问卷、数据文件、课程报告 |
| 行政实习转综合岗 | 资料整理、会议或日常事务支持、按要求提交文件 | 文档整理、按流程执行、任务收尾 | 不要把行政支持改成业务决策或项目主导 | 文件版本、工作安排、负责人反馈 |
| 公众号或校园账号 | 选题、排版、发布或简单内容维护 | 内容整理、发布执行、用户视角 | 没有后台数据就不要写阅读量和增长率 | 排版文件、后台截图、发布记录 |
| 班委或志愿活动 | 通知、签到、物资、秩序或现场协助 | 沟通、排期、现场执行 | 参与者不能写成总负责人 | 活动通知、签到表、照片、聊天记录 |

## 示范档案一｜奶茶店兼职 → 用户运营、服务运营岗（对应案例09）

| 档案字段 | 填写内容 |
|---|---|
| 原始事实 | 大二暑假，校外某奶茶店，店员，为期两个月；工作内容为点单、制作饮品、门店清洁整理 |
| 个人贡献 | 高峰期由我判断出单顺序（按等待时长）并向排队顾客口头同步预计等待时间；店长缺位时由我独自处理一起口味投诉（重做一杯并赠券） |
| 数据来源 | 无后台数据；排班表照片可证明在职与出勤；投诉顾客后续回购为本人当班目击，无书面记录 |
| 对应能力 | 压力下的优先级判断／顾客预期管理／授权模糊时的现场补救决策 |
| 简历表达 | 暑期奶茶店兼职两个月：高峰期按顾客等待时长安排出单顺序并主动同步预计等待时间；曾在店长缺位时通过重做与赠券化解一起口味投诉，该顾客此后仍回店消费；兼职期间基本全勤。 |
| 禁止夸大 | 不写日均杯数（没数过）；不写「负责客诉处理」（只有一次）；不写「提升门店营业额」（未参与经营）；不把「基本全勤」写成「全勤」 |
| 面试深挖 | 怎么判断谁等最久／报的时间不准怎么办／怎么确认真做错了／赠券权限谁给的／店长事后怎么说／顾客坚持投诉怎么办／这家店哪里做得不好／柜台经验对线上运营有什么用 |
| 回答材料 | 事实：小票顺序判断等待时长；过程：先确认口味确实做错→当场决定重做＋赠券→留店长电话备用；困难：无明确授权，自担判断责任；结果：顾客息事且回购；复盘：报等待时间宁可报宽，早于承诺完成 |
| 真实性检查 | 每个动作均为本人所做✓；未使用任何无来源数字✓；三层追问内容已备✓；未将参与写成主导（本就是独立当班）✓；删掉修饰词后经历仍成立✓ |

|---|---|

| 数据来源 | 问卷截图、导出的原始数据表、清洗后数据表、报告成稿；回收份数未核实（需打开原始数据表清点后才能写） |
| 对应能力 | 把模糊问题转成可回答的题目／基础数据清洗与图表呈现／用数据支撑结论的书面表达 |

| 禁止夸大 | 不写「主导项目」（讨论定题、报告合写）；不写回收份数与有效率（未清点）；不写「分层抽样」「交叉分析」等未使用的方法名；不写「为门店提供建议」等不存在的商业结果 |

| 回答材料 | 事实：问卷经小组讨论、初稿为本人撰写；过程：设计→投放（年级群＋朋友圈）→清洗（同选项连选、时长过短、开放题乱写为剔除标准）→制图→撰写；困难：样本集中本校且有自选偏差；结果：报告完整交付；复盘：结论只对校内样本成立，扩样与访谈是改进方向 |
| 真实性检查 | 动作均为本人✓；数字一个未写、待清点后补✓；三层追问已备（含主动承认样本局限）✓；「主要执行」而非「主导」，边界已画清✓；删掉修饰词经历成立✓ |

|---|---|

| 对应能力 | 单据合规审核的基础动作／按规则执行不受人情干扰／事务性工作的流程化落地 |

| 禁止夸大 | 不写单据数量与经手金额（未知）；不写「多次拦截违规报销」（一次）；不写「参与完善报销制度」（未参与）；不写「获领导好评」（未经确认） |
| 面试深挖 | 具体核哪几项／那次差在哪、怎么发现的／退单时怎么开口的／动摇过吗、为什么不通融／对方找主管施压怎么办／拿不准的单据怎么处理／小公司核对和银行审核差距在哪／中文系→行政→银行的逻辑讲通 |

## 一分钟自我介绍


### 组装方法

完整的自我介绍不从一段经历硬凑。正确用法是：

1. 打开你填好的联动档案，选出与目标岗位最相关的两张经历卡；
2. 从两张卡里各取一句「简历表达」和一项「对应能力」；
3. 按下面的时间结构组装。

### 时间结构（按约一分钟练习）

- 8秒：姓名、学校、专业、目标岗位
- 15秒：第一段核心经历＋它证明的能力
- 15秒：第二段核心经历＋它证明的能力
- 12秒：两段经历与该岗位要求的对应关系
- 10秒：求职动机与自然收尾

### 填空模板

> 面试官好，我是［姓名］，［学校］［专业］应届生，应聘的是［岗位名称］。
> 我想用两段经历说明我的准备：第一段，［经历卡A的简历表达，压缩到一句］，这段经历里我实际做到的是［经历卡A的对应能力，用具体动作说，不用能力名词］。
> 第二段，［经历卡B的简历表达，压缩到一句］，其中［经历卡B里最可能被追问、你也最有把握回答的细节点一下即可］。
> 这个岗位据我理解，日常最需要的是［岗位的一至两项核心要求，来自JD页面］，而这两段经历分别对应了其中的［对应关系一句话说清］。
> 我选择这个岗位是因为［真实动机一句，禁用套话］，以上是我的介绍，谢谢。

### 完整示范

示范中的岗位要求和人物为模拟设定。完整示范的两段经历属于同一虚构候选人。

> 面试官好，我是示例学生，某大学汉语言文学专业应届生，应聘贵行的综合柜员岗。
> 我想用两段经历说明我的准备：第一段，我在一家公司行政岗实习了三个月，每月的报销单由我逐张核对金额与发票、贴票，不符的退回补充——有一次同事的单据金额和发票对不上，他不太高兴，我还是按流程退了。
> 第二段，我做过两年班级生活委员，班费逐笔记账、每学期向全班公示，保留了班费台账和公示材料。
> 柜员岗据我理解，示例 JD 要求的两项任务是单证核对和按规操作，报销核对练的是前者，班费记账与公示练的是后者。
> 我选择银行，是因为实习让我发现自己最有耐心、也做得最稳的恰好是核单据这类工作，以上是我的介绍，谢谢。

### 过度包装版与自然版对比（用于自查）

过度包装版（反面示例，禁止模仿）：
> 我具备较强的沟通协调能力和抗压能力，在实习中深度参与公司财务管理工作，多次拦截违规报销，获得领导一致好评，相信我能为贵行创造价值。

自然版（参见完整示范）与它的区别：
- 包装版全是能力名词，自然版全是动作和事件；
- 包装版的每一句都经不起「举个例子」，自然版每一句本身就是例子；
- 包装版把一次说成多次、把执行说成管理，面试追问两层即穿。

### 自我介绍真实性检查表

- 里面提到的每件事，都能在我的联动档案里找到对应的卡吗？
- 有没有任何一句话是档案里没有、我临时加上去的？
- 「岗位要求」那句是我从JD里读来的，还是我猜的？
- 动机那句，如果面试官追问「为什么」，我还有下一层真话吗？
- 全文读一遍，有没有出现「较强的」「丰富的」「深度」这类没有事实跟着的词？

## 面试一致性检查

逐条复述简历中的动词和结果，问三层问题。

1. **做了什么**。指出本人负责的步骤和团队分工。
2. **怎么做**。讲清顺序、关键判断和一次实际核对。流程未确认时仅写已知动作。
3. **证据在哪**。指出可说明的交付物、记录或复核人，练习材料用脱敏版本。没证据支撑的数字或结果从简历中移除。

用「本人动作 → 交付物 → 可核对结果」组织句子。例如确认过记录与公示时，可写「整理班费收支记录，形成公示内容，向班级公开使用情况」。台账字段、频率和金额都需要独立确认。
