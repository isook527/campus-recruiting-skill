# 面试题与追问

先选一道与岗位相关的题。每轮只问一题，用户回答后追问本人贡献、证据及缺口。最后整理成「情境 → 本人任务 → 动作 → 结果与边界」。用当前 JD 判断题目是否相关。准备多轮面试前先用[故事矩阵](story-matrix.md)确认哪些经历可复用；需要银行、快消、互联网、群面、HR 面、压力追问、终面或反问时，再打开[分行业与轮次题库](interview-question-bank.md)。下列问题用于普通练习。

## 20 道通用面试题

| 类别 | 问题 | 准备重点 | 避免事项 |
| --- | --- | --- | --- |
| 基础信息 | 请简单介绍一下自己 | 身份信息→目标岗位→两段真实经历 | 不要堆砌成绩、奖项和未经核实的经历 |
| 基础信息 | 为什么选择我们公司？ | 公司公开信息→岗位要求→个人证据 | 不要只说行业知名、平台大、想学习 |
| 基础信息 | 你的优缺点是什么？ | 各给一个具体行为例子 | 不要用没有例子的“沟通能力强” |
| 基础信息 | 为什么选择这个专业？ | 真实选择原因→学到的可迁移方法 | 不要把专业经历拔高成职业规划结论 |
| 基础信息 | 大学期间最大的收获是什么？ | 选择一件有过程、有结果的事 | 不要只说“成长很多” |
| 个人能力 | 你最大的成就是什么？ | 任务背景→本人动作→可证明结果 | 没有可靠数字就不量化 |
| 个人能力 | 描述一次你解决过的困难 | 困难→判断→行动→复盘 | 不要把团队成果全部写成自己完成 |
| 个人能力 | 描述一次你主动承担额外责任的经历 | 为什么承担→具体做了什么→怎么收尾 | 不要把一次临时帮忙写成长期负责 |
| 个人能力 | 你的核心竞争力是什么？ | 用两段经历证明同一能力 | 不要脱离经历单独背概念 |
| 学习成长 | 你如何保持学习动力？ | 一个真实学习任务和完成方式 | 不要虚构长期打卡或证书 |
| 学习成长 | 你最感兴趣的领域是什么？ | 兴趣来源→做过的具体了解 | 不要只报一个热门领域名称 |
| 学习成长 | 你如何学习新知识？ | 资料来源→练习动作→验证结果 | 不要声称熟练使用未用过的工具 |
| 学习成长 | 你如何看待批评？ | 一次具体反馈和调整 | 不要只回答“虚心接受” |
| 学习成长 | 你觉得自己还要提升什么？ | 岗位相关短板→正在采取的动作 | 不要选择“没有缺点” |
| 实习项目 | 实习经历对求职有什么帮助？ | 把实习动作和目标岗位要求连接起来 | 不对口经历也不能改成不存在的职责 |
| 职业规划 | 你的职业规划是什么？ | 先说近期岗位方向和可执行学习计划 | 不要承诺过于具体的晋升结果 |
| 职业规划 | 为什么选择这个岗位？ | 岗位任务→本人证据→动机 | 不要只说“符合专业” |
| 职业规划 | 你对这个岗位的理解是什么？ | 从JD动作词提炼日常工作 | 不要只复述岗位名称 |
| 反问环节 | 你还有什么想了解的吗？ | 准备工作内容、团队协作、培养方式等问题 | 不要问公告上已经写清楚的内容 |
| 复盘 | 如果重做一次，你会改变什么？ | 指出一个真实可改动作 | 不要把结果改写成虚构的成功故事 |

## 12 条深挖追问

| 适用方向 | 追问 | 回答方式 |
| --- | --- | --- |
| 所有经历 | 当时为什么做这件事？ | 先说场景和本人选择，不先说抽象能力 |
| 所有经历 | 你本人具体负责什么？ | 只说自己的动作和边界 |
| 所有经历 | 和其他人怎样分工？ | 讲清谁负责什么，避免把团队成果归给自己 |
| 所有经历 | 遇到过什么困难？ | 给出一个真实卡点和当时处理方式 |
| 所有经历 | 结果如何证明？ | 使用文件、记录、反馈或可复述事实 |
| 所有经历 | 如果重做会改变什么？ | 说一个具体、可执行的改进动作 |
| 所有经历 | 这段经历为什么适合目标岗位？ | 把经历动作对应到岗位任务，不只说“能力强” |
| 所有经历 | 面试官继续追问三层怎么办？ | 回到事实、边界和证据，不临时补数字 |
| 运营/市场/内容 | 你如何判断内容或活动是否有效？ | 先说使用过的观察指标，没有数据就说观察方式 |
| 银行/金融/综合职能 | 你如何保证资料准确？ | 说核对、整理、复查步骤，不虚构系统经验 |
| 人力/行政/项目支持 | 多人信息不齐时怎么办？ | 说收集、提醒、记录和截止时间管理 |
| 技术倾向岗位 | 岗位是否需要技术技能？ | 回到具体JD，不套用非技术案例 |

## 一道题的深挖顺序

不要一次抛出整套题。先问主问题，收到回答后只选最能改变评分的一层：

1. **本人动作**：「这里哪一步是你本人做的？」
2. **判断依据**：「当时有哪些选项，为什么选这一种？」
3. **证据边界**：「能用什么核对？哪些数字或结果没有留存？」
4. **反事实**：「如果关键条件变化，你会先改哪一步？」

用户说「我们」时先拆本人贡献；新出现的数字、任期或职责先待确认；面试官式挑战题也先核前提，不为了显得坚定而接受错误假设。评分与同题复练使用[同一量表](interview-coaching.md)。
