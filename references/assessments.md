# 测评、笔试与线上任务

用于处理性格测评、能力测评、专业笔试、英语测试、AI 面试、在线作业和群面前任务。先核邀请和规则，再准备。不代答正在进行的测评，不帮助绕过监考、身份核验或时间限制。

## 开始前最少事实

- 单位、岗位和批次
- 邀请来源、登录域名及是否能从官方招聘系统回溯
- 开始与截止时间、时区、预计时长、尝试次数
- 题型、语言、设备、浏览器、摄像头和网络要求
- 是否允许草稿纸、计算器、外部资料或中途暂停
- 异常处理和官方联系人

缺少上述事实时，先给准备清单。是否参加、何时参加及能否重试保持「待核」。

## 邀请核验

1. 从投递记录或官方招聘系统确认自己确实投过同一岗位。
2. 对照邮件域名、岗位、候选人姓名、截止时间和链接域名。
3. 第三方测评平台必须能由招聘方官方邮件、公告或系统跳转证明关联。
4. 若要求付款、下载不明程序、提供支付信息或开启远程控制，按 [投递安全](application-safety.md) 暂停。
5. 登录页打不开、信息冲突或联系人无法回溯时，记录现象并使用招聘方官方渠道确认。不要反复尝试导致次数耗尽。

邀请中的个人链接、候选人编号、账号和验证码不复制进公开笔记或求助截图。平台名称只能帮助找官方支持，不能单独证明邀请真实。

## 常见平台只确认能力边界

同一平台可由不同招聘方配置不同题型、语言、时限、监控、身份核验和重试规则。下面只记录平台官方公开页能支持的事实；本次邀请的具体规则仍以招聘方通知和登录后的正式说明为准。

| 平台 | 官方公开信息能确认什么 | 候选人可做的准备 | 不能据此推断 |
| --- | --- | --- | --- |
| 北森 | 北森官方的[人才测评产品页](https://www.beisen.com/product/evaluation/)展示招聘测评、在线考试等多类应用；[校园招聘方案](https://www.beisen.com/solution/campus/)还列出测评、笔试与 AI 面试等可组合环节 | 沿招聘方官方链路打开邀请，逐项抄下本次题型、设备、权限和截止；只练通知明确的类型 | 不能因页面展示某项产品就认定本次一定有该题型、摄像头、AI 面试或固定时长 |
| SHL | SHL 的[候选人支持页](https://support.shl.com/candidate)提供登录、限时测评、系统与浏览器检查和技术支持入口；[官方练习说明](https://support.shl.com/category.html?c=10_91_12_54_55_&hl=en)说明免费练习主要用于熟悉作答方式，而且并非覆盖所有测评和语言 | 先跑官方 Browser Check；若本次题型有对应官方练习，用来熟悉界面与节奏，故障按候选人支持流程记录 | 练习题不证明正式题目相同，不预测分数线；邀请是否可用手机、是否能暂停或重进要看本次页面 |
| 智鼎在线 | 智鼎官方[产品页](https://hr.zhiding.com.cn/zhiding/introduce/evaluationProductsPage)列出能力、性格、动机与价值观等类别；[隐私与用户协议](https://hr.zhiding.com.cn/zhiding/htmls/agreement.htm)说明候选人由应聘企业邀请，企业配置可能涉及实名、相机或麦克风权限 | 确认邀请能回溯到应聘企业，阅读本次收集字段和权限提示；不理解或不愿提供某项敏感信息时先联系招聘方 | 不能把某一种登录信息、实名方式、摄像头权限或题量写成所有智鼎邀请的统一格式 |

## 按类型准备

| 类型 | 练什么 | 不做什么 |
| --- | --- | --- |
| 行测或能力测评 | 题型识别、限时取舍、基础计算和读表 | 不承诺题库命中或预测分数线 |
| 申论或材料写作 | 材料概括、问题分析、对策题和应用文 | 不套用与题目无关的万能范文 |
| 专业笔试 | 按 JD 的核心任务整理概念、案例和计算步骤 | 不把网上经验帖当本轮官方范围 |
| 英语测试 | 自我介绍、岗位词汇、阅读与书面表达 | 不编造语言成绩或工作经历 |
| 性格或情境测评 | 理解题意、按真实稳定的工作行为作答 | 不教用户伪装某种「标准人格」 |
| AI 面试或录播题 | 镜头、收音、结构化表达和限时练习 | 不代录、不用虚拟替身规避身份要求 |
| 在线作业或案例 | 复述目标、列假设、说明数据来源和交付边界 | 不提交他人作品，不把模拟结果写成真实业绩 |

## 一次可执行的准备

1. 用官方规则建立题型与时间表。
2. 做一轮短基线，记录耗时、错误类型和卡点。
3. 只针对最影响完成度的一到两个问题练习。
4. 按真实时长做一次模拟，检查设备、文件和提交方式。
5. 正式开始前关闭无关通知，准备规则允许的物品并确认电源与网络。
6. 完成后保存提交确认页和时间。若遇故障，保留截图并尽快走官方异常渠道。

## 申论格式练习

- **材料概括**：按主体、问题、原因、影响或做法标注原文，合并同义信息。答案只写材料能支持的要点。
- **提出对策**：每条用「问题 → 动作 → 执行主体或对象 → 可检查结果」，先确认题目要求是依据材料还是允许补充常识。
- **应用文**：先核文种、身份、对象、目的和字数，再写标题、称谓、正文、落款等题目要求的格式。公告未明确格式时不臆造扣分规则。

练习时使用同一材料分别做限字概括、对策和应用文，复盘遗漏点、重复点、无材料依据和格式错误。

## 三类面试格式练习

### 结构化作答

用「结论 → 依据 → 本人动作 → 结果或反思」练 60 秒和 120 秒两个版本。题目一次只练一道。复练时沿用同一评分维度，重点检查是否回答题目、事实是否可追问、是否在时限内完成。不背诵虚构模板。

### 无领导小组讨论

先核官方通知中的人数、时长、材料阅读、个人陈述、自由讨论和总结规则。练习时轮换记录、计时、澄清、推进和总结等行为，不预设必须争抢领导角色。评分关注：是否理解任务、是否引用材料、是否帮助形成共同结论、是否尊重他人发言、本人贡献能否具体复盘。

群面里的「角色」是可观察行为，不是入场前固定头衔：提出判断标准、整理分歧、补充材料依据、提醒时间、邀请沉默成员、检验结论和总结都可以形成贡献。同一人可切换行为，也可以不做总结。练习银行、快消、互联网场景和不同贡献方式时，从[分行业与轮次题库](interview-question-bank.md#小组面试的贡献方式)只选一个场景，不照搬固定角色话术。

### AI 录制或录播面试

先确认题数、读题与作答时长、重录次数、语言和设备要求。练习时使用与正式环境相近的镜头、收音和计时，回看开头是否直接回答、例子是否真实、视线和声音是否稳定。不得使用虚拟替身、预录替换或其他规避身份与监考要求的方式。

## 结果解释

- 只有官方通知能证明是否进入下一环节。自测分、论坛分数线和答题感受不能替代结果。
- 「已完成」只表示提交成功，不等于通过。
- 性格测评结果只能结合具体报告解释，不给人格或职业适配下确定性诊断。
- 用户问「要不要参加」时，先核真实性、截止、岗位意愿和时间成本。关键事实不足时只给条件式判断，不做最终推荐。

## 输出格式

```markdown
**状态**：已核 / 待核 / 冲突
**官方规则**：截止、时长、次数、设备、允许材料
**准备重点**：最多 3 项
**风险与缺口**：只列会影响参加或提交的事实
**下一步**：一个可立即执行的动作
```
