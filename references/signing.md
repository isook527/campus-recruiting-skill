# Offer、三方与协议文本复核

这是阅读和提问框架，不替代针对具体文本的法律意见。各学校、地区、单位和协议版本可能不同。只按用户实际拿到的完整文本回答，避免用通用经验推断条款效力或违约结果。

## 先分清文件

分别收集并命名，不把一份文件的约定自动套到另一份：

- 录用意向或 Offer letter
- 就业协议、三方协议或学校就业系统中的确认
- 劳动合同及员工手册
- 培训、服务期、保密、竞业或知识产权协议
- 补充协议、附件、薪酬说明和书面承诺

确认是否拿到全部页、附件、版本日期、签署主体和盖章页。空白处、手写修改和引用但未附的制度单独列出。

## 逐项复核

| 项目 | 从文本找什么 | 向对方确认什么 |
| --- | --- | --- |
| 主体 | 单位全称、统一社会信用代码、签章主体 | 招聘、签约和实际用工主体是否一致 |
| 岗位与地点 | 岗位名称、职责、城市、具体地点、调动范围 | 轮岗、派驻、调岗和异地安排的边界 |
| 报酬 | 固定、浮动、奖金、补贴、发放周期和条件 | 宣传口径与文本口径为何不同 |
| 入职与试用 | 报到日期、试用安排、转正条件 | 延期毕业、证书未取得或背调未完成如何处理 |
| 时间与休息 | 工时安排、休息休假、出差和值班 | 岗位实际执行口径及审批方式 |
| 社保与福利 | 社保、公积金、保险、住宿、餐补等 | 缴纳地、起算时间和适用条件 |
| 培训与服务 | 培训项目、费用、服务期及责任 | 触发条件、计算依据、证明材料和退出流程 |
| 保密与竞业 | 范围、期限、地域、对象及补偿安排 | 哪些岗位适用、何时生效、如何解除 |
| 户口与档案 | 办理主体、条件、时间和未办成处理 | 这是承诺、目标还是需另行审批的事项 |
| 背调 | 授权范围、信息类型、第三方、时间和异议渠道 | 何时启动、联系谁、结果异常如何核对或补充说明 |
| 体检 | 机构、项目、时间、费用、结果接收方和复检安排 | 是否指定机构、哪些项目与岗位相关、异常结果如何复核 |
| 撤回与解约 | 解除、撤回、通知、材料返还及责任 | 学校、单位和个人各自要走什么流程 |
| 个人信息 | 收集字段、用途、接收方和保存安排 | 非当前阶段必需字段为何需要、由谁处理 |

不要预设某类条款必然有效或无效。遇到金额、期限、责任、竞业、培训或身份资格争议时，引用原文，列问题，并建议向学校就业办、当地公共就业或人社服务渠道、律师等合适主体核对。

## 背调与体检的具体处理

### 背调

1. 先拿到授权说明，确认调查主体、信息范围、联系人、开始时间和结果用途。
2. 按真实经历准备公司或学校全称、日期、角色和可联系证明人。先征得证明人同意，不替对方编答案。
3. 学籍、经历或日期存在可解释差异时，主动整理原始材料和书面说明，不自行修改历史记录。
4. 收到「背调异常」通知时，先索取具体差异和补充材料渠道。没有细节时不猜测录用结果。

### 体检

1. 从官方通知确认指定机构、项目、预约方式、截止时间、费用承担和是否允许复检。
2. 对通知中的准备要求有疑问时直接问体检机构或招聘方，不依据网络经验改变用药或隐瞒信息。
3. 健康报告和影像属于敏感材料，不在普通聊天或共享投递记录中保存完整版本。
4. 出现异常或岗位相关限制时，先确认复检、补充报告和申诉流程。由专业医疗人员解释医学结果，本 Skill 不下诊断。

## 审阅输出

每个重要条款按同一格式：

```markdown
**原文**：不超过必要长度的准确摘录
**通俗含义**：只解释文字，不推断未写内容
**待确认**：一个能补齐事实的问题
**影响**：若按该口径执行，会影响什么决定
**状态**：明确 / 有歧义 / 缺附件 / 与其他材料冲突
```

先列会改变是否签署的 P0 项，再列可在入职前补齐的 P1 项。P0 常包括主体、岗位地点、报酬口径、入职条件、服务与退出责任。具体项目仍以本份文本为准。

## 被催促签署时

1. 先取得完整可保存文本和全部附件。
2. 用书面方式确认接受截止及能否延长，不把口头催促当成文本事实。
3. 对主体、报酬、地点、服务期、责任或空白处仍有疑问时，列出问题并暂停最终建议。
4. 需要在短时间内决定时，优先核 P0 项。时间紧不等于可以跳过文本。
5. 未拿到完整事实时只给「签前必须补核」清单，不说「放心签」或「一定不要签」。

## 可复制问题

> 为确保我理解一致，想请您书面确认：1）签约及实际用工主体。2）岗位和工作地点及可能调整范围。3）固定、浮动薪酬与发放条件。4）试用、培训或服务期安排。5）撤回或解约流程及相关责任。另请提供协议引用的全部附件和适用制度，谢谢。

背调与体检可另问：

> 想确认本岗位背调与体检安排：背调由谁实施、核验哪些信息、何时取得授权、如有差异如何补充说明。体检是否指定机构与项目、费用由谁承担、报告由谁接收、如有异常是否有复检或补充材料流程。烦请以本批次书面规则为准，谢谢。

官方规则入口见 [官方入口与核验状态](official-sources.md)。比较多个机会时读 [Offer 比较与决定](offer-decision.md)。
