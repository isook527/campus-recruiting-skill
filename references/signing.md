# Offer、三方与协议文本复核

这是阅读和提问框架，不替代针对具体文本的法律意见。各学校、地区、单位和协议版本可能不同。只按用户实际拿到的完整文本回答，避免用通用经验推断条款效力或违约结果。

## 先分清文件

分别收集并命名，不把一份文件的约定自动套到另一份：

- 录用意向或 Offer letter
- 就业协议、三方协议或学校就业系统中的确认
- 劳动合同及员工手册
- 培训、服务期、保密、竞业或知识产权协议
- 补充协议、附件、薪酬说明和书面承诺

确认是否拿到全部页、附件、版本日期、签署主体和盖章页。空白处、手写修改和引用但未附的制度单独列出。

## 逐项复核

| 项目 | 从文本找什么 | 向对方确认什么 |
| --- | --- | --- |
| 主体 | 单位全称、统一社会信用代码、签章主体 | 招聘、签约和实际用工主体是否一致 |
| 岗位与地点 | 岗位名称、职责、城市、具体地点、调动范围 | 轮岗、派驻、调岗和异地安排的边界 |
| 报酬 | 固定、浮动、奖金、补贴、发放周期和条件 | 宣传口径与文本口径为何不同 |
| 入职与试用 | 报到日期、试用安排、转正条件 | 延期毕业、证书未取得或背调未完成如何处理 |
| 时间与休息 | 工时安排、休息休假、出差和值班 | 岗位实际执行口径及审批方式 |
| 社保与福利 | 社保、公积金、保险、住宿、餐补等 | 缴纳地、起算时间和适用条件 |
| 培训与服务 | 培训项目、费用、服务期及责任 | 触发条件、计算依据、证明材料和退出流程 |
| 保密与竞业 | 范围、期限、地域、对象及补偿安排 | 哪些岗位适用、何时生效、如何解除 |
| 户口与档案 | 办理主体、条件、时间和未办成处理 | 这是承诺、目标还是需另行审批的事项 |
| 背调 | 授权范围、信息类型、第三方、时间和异议渠道 | 何时启动、联系谁、结果异常如何核对或补充说明 |
| 体检 | 机构、项目、时间、费用、结果接收方和复检安排 | 是否指定机构、哪些项目与岗位相关、异常结果如何复核 |
| 撤回与解约 | 解除、撤回、通知、材料返还及责任 | 学校、单位和个人各自要走什么流程 |
| 个人信息 | 收集字段、用途、接收方和保存安排 | 非当前阶段必需字段为何需要、由谁处理 |

不要预设某类条款必然有效或无效。遇到金额、期限、责任、竞业、培训或身份资格争议时，引用原文，列问题，并建议向学校就业办、当地公共就业或人社服务渠道、律师等合适主体核对。

## 背调与体检的具体处理

### 背调

1. 先拿到授权说明，确认调查主体、信息范围、联系人、开始时间和结果用途。
2. 按真实经历准备公司或学校全称、日期、角色和可联系证明人。先征得证明人同意，不替对方编答案。
3. 学籍、经历或日期存在可解释差异时，主动整理原始材料和书面说明，不自行修改历史记录。
4. 收到「背调异常」通知时，先索取具体差异和补充材料渠道。没有细节时不猜测录用结果。

### 体检

1. 从官方通知确认指定机构、项目、预约方式、截止时间、费用承担和是否允许复检。
2. 对通知中的准备要求有疑问时直接问体检机构或招聘方，不依据网络经验改变用药或隐瞒信息。
3. 健康报告和影像属于敏感材料，不在普通聊天或共享投递记录中保存完整版本。
4. 出现异常或岗位相关限制时，先确认复检、补充报告和申诉流程。由专业医疗人员解释医学结果，本 Skill 不下诊断。

## 审阅输出

每个重要条款按同一格式：

```markdown
**原文**：不超过必要长度的准确摘录
**通俗含义**：只解释文字，不推断未写内容
**待确认**：一个能补齐事实的问题
**影响**：若按该口径执行，会影响什么决定
**状态**：明确 / 有歧义 / 缺附件 / 与其他材料冲突
```

先列会改变是否签署的 P0 项，再列可在入职前补齐的 P1 项。P0 常包括主体、岗位地点、报酬口径、入职条件、服务与退出责任。具体项目仍以本份文本为准。

## 被催促签署时

1. 先取得完整可保存文本和全部附件。
2. 用书面方式确认接受截止及能否延长，不把口头催促当成文本事实。
3. 对主体、报酬、地点、服务期、责任或空白处仍有疑问时，列出问题并暂停最终建议。
4. 需要在短时间内决定时，优先核 P0 项。时间紧不等于可以跳过文本。
5. 未拿到完整事实时只给「签前必须补核」清单，不说「放心签」或「一定不要签」。

## 接受、三方与退出不是同一步

先定位用户处于哪一层，再讨论退出：

| 当前状态 | 先找的文本 | 需要确认的动作与成本 |
| --- | --- | --- |
| 只有口头意向 | 邮件、系统状态 | 是否已有书面 Offer，口头撤回是否需要操作 |
| 已收未接受 Offer | Offer 与接受页面 | 截止、何种动作算接受、到期后状态 |
| 已接受 Offer | 接受邮件、系统记录、附件 | 撤回流程、通知对象、是否有已发放款项或材料 |
| 已签三方或就业协议 | 完整协议、补充条款、学校流程 | 解约主体、书面同意、学校手续、时间和文本约定的责任 |
| 已签劳动合同 | 劳动合同、员工手册、专项协议 | 生效与入职时间、解除流程、培训或服务期等具体文本 |
| 已入职 | 全部签署文件与实际履行记录 | 不再按普通校招退出模板处理，需结合实际文本和专业意见 |

不要把「拒绝 Offer」「撤回接受」「三方解约」「劳动合同解除」混为同一个动作。

## 三方退出成本清单

「成本」不只是一笔金额。逐项核：

- 协议是否写明违约责任、触发条件、金额或计算方式、收款主体
- 是否另有培训、服务期、签约奖金、搬迁或预支费用协议
- 单位是否要求书面解约申请、释放函或其他材料
- 学校就业系统需要哪些主体确认、预计多长时间、状态何时更新
- 新单位的签约截止是否能覆盖原单位和学校流程
- 户口、档案、政审、背调或体检材料是否已经进入办理流程，如何停止或转接
- 已交证件原件、盖章材料或个人信息如何返还、删除或更正

只从实际文本提取责任，不替任何一方断言条款一定有效或无效。金额、责任或办理争议会改变决定时，带完整文本咨询学校就业办、当地公共就业或人社服务渠道、律师等合适主体。

向原单位和学校分别问：

> 我目前处于 `{已接受 Offer / 已签就业协议}` 状态，现需了解撤回或解约流程。请书面告知：需要哪些主体同意、材料与系统步骤、预计完成时间，以及协议中可能触发的费用或其他责任的具体条款和计算依据。若已有户口、档案、体检或背调流程，也请说明如何停止或转接。

## 上海落户：按毕业年度做条件式核验

上海非上海生源应届毕业生进沪就业申请户籍按年度通知和办法办理。对 2027 届候选人，2026 年文件只能用来建立问题清单，不能提前当作 2027 年资格或分数结论。

签约前依次确认：

1. 目标毕业年度的正式通知、户籍申请办法、评分办法和受理时间是否已发布。
2. 本人是否属于该年度文件覆盖的毕业生范围。
3. **签约法人**是否具备当年为非上海生源毕业生申请户籍的资格，而不只问集团品牌是否「有名额」。
4. 申请走哪一条具体路径、个人和单位分别需要哪些材料；涉及评分时按当年表逐项核，不凭往年分数预测。
5. 单位何时申报、由谁负责、错过或审核未通过时就业协议和岗位如何处理。
6. HR 的说明是否进入邮件或协议；「协助申请」不等于审批结果保证。

2026 年上海官方通知要求高校提醒毕业生核实单位申请资格，并要求用人单位在签就业协议时如实告知其是否具备申请资格；该通知同时说明具体申请按 2026 年附件办法和评分办法执行。[上海市 2026 年通知](https://www.shanghai.gov.cn/gwk/search/content/f4df3bb5b82747b893b1eb10ca2b1f8b)，发布于 2026-05-06，核验于 2026-11-09。

可复制问题：

> 请问与我签约的法人是否具备 `{毕业年度}` 非上海生源应届毕业生户籍申请资格？本岗位拟按哪条当年政策路径申报，单位经办人和预计节点是什么？如果当年政策变化、单位未取得资格或申请未通过，岗位、就业协议和双方责任如何处理？烦请提供对应年度官方依据并书面确认。

## 北京引进毕业生：不要把「进京指标」当口头保证

北京市现行市级办法使用引进毕业生计划和指标分配机制，并由市人社部门、主管单位、用人单位分级办理。候选人仍需满足适用范围，用人单位需在相应计划和申报流程内提交，最终还要经过审核；因此「单位有指标」不等于个人已获批。

签约前依次确认：

1. 适用北京市现行办法、中央单位渠道还是其他明确政策，负责的主管单位是谁。
2. 签约法人是否获得对应毕业年度的引进计划或指标，是否明确用于本岗位和本人申报。
3. 本人的招生、培养、就业和毕业时间是否符合适用办法；不要只凭学校或学历标签判断。
4. 单位拟选择的申报月份、材料、公示和审核节点。
5. 单位与本人拟约定的落户期限及期间的劳动关系、社保和服务安排。
6. 指标未获分配、个人审核未通过、延期毕业或办理前离职时，岗位、协议和双方责任如何处理。

[《北京市引进毕业生管理办法》官方页面](https://rsj.beijing.gov.cn/xxgk/2024zcwj/202406/t20240617_3717192.html)标注京人社毕发〔2021〕22 号为现行有效，并列出指标分配、申报、公示、审核和落户阶段；发布页核验于 2026-11-09。[北京市行政确认事项页面](https://rsj.beijing.gov.cn/xxgk/zfxxgk/zdlygk/qlqd/xzqr/)显示申请主体为用人单位、主管单位，并列明线上办理和市区两级权限；核验于 2026-11-09。若目标单位不走该市级渠道，应要求其说明适用的官方依据。

可复制问题：

> 请问本岗位的签约法人通过哪一主管单位、按哪项官方政策办理非北京生源毕业生引进？单位是否已获得 `{毕业年度}` 对应计划或指标，并拟为本人申报？预计申报、审核和落户期限分别是什么？若指标、审核或毕业时间发生变化，岗位、就业协议和双方责任如何处理？烦请以书面口径回复。

## 可复制问题

> 为确保我理解一致，想请您书面确认：1）签约及实际用工主体。2）岗位和工作地点及可能调整范围。3）固定、浮动薪酬与发放条件。4）试用、培训或服务期安排。5）撤回或解约流程及相关责任。另请提供协议引用的全部附件和适用制度，谢谢。

背调与体检可另问：

> 想确认本岗位背调与体检安排：背调由谁实施、核验哪些信息、何时取得授权、如有差异如何补充说明。体检是否指定机构与项目、费用由谁承担、报告由谁接收、如有异常是否有复检或补充材料流程。烦请以本批次书面规则为准，谢谢。

官方规则入口见 [官方入口与核验状态](official-sources.md)。比较多个机会时读 [Offer 比较与决定](offer-decision.md)。
