# 投递前检查与防骗

## 每次投递检查

1. 招聘主体、岗位 ID、招聘类型和公告属于同一轮。
2. 官网或官方授权的 ATS 可查到同一项目和岗位。跳转域名、单位、届次一致。
3. 毕业时间、学历、专业、国籍/工作资格、证书等硬性要求符合。偏好项单列。
4. 城市、校招/实习性质、到岗时间及实习周期能接受。
5. 截止日期、时区、志愿顺序及次数来自本轮官方公告。
6. 确认岗位所需证据、需要补问的信息和本人能说明的事实。
7. 用对应方向的简历，逐项对照网申中的学历、成绩、经历和时间。
8. 检查文件名、格式、大小、顺序及附件能否打开，删去样例占位符。
9. 使用本人可收信的渠道，确认手机号、邮箱和通知设置。仅在可信官方渠道填写必需字段。
10. 看清提交后是否能修改、能否重复投递和是否允许调剂。
11. 遇到收费、贷款、验证码、远程控制或陌生私链时暂停。
12. 由本人完成提交，保留确认页、提交时间、简历版本、测评与下一步日期。

## 识别常见风险

| 信号 | 先做什么 |
| --- | --- |
| 报名费、押金、设备费或以保证金保留岗位 | 先不付款，通过用人单位官网复核 |
| 付费内推、央国企保录、保 Offer、保直签 | 回到官方流程，拒绝为面试名额、录用资格付费 |
| 面试被转成培训、分期或入职后扣费 | 分别核对招聘、培训和放款主体，现场不签培训或贷款合同 |
| 要充值、垫付订单、刷单或购买商品才能试岗 | 停止付款并保留聊天与转账证据 |
| 要短信码、银行卡密码、人脸认证或远程操控 | 停止操作，退出远控并按账号官方流程处理 |
| 个人社交账号投递、主体模糊或报酬异常 | 查公司官网、平台认证和中介资质，核对单位全称与合同主体 |
| 模糊高薪、空白合同、扣留证件、要求代收转账 | 核清职责、地点、报酬和合同条款，避免交付原件及处理来源不明资金 |
| 过度收集身份证、户口、家庭与财务信息 | 核对官方要求、使用目的和提交阶段，公开材料做脱敏 |

账号有认证只说明平台做过某种核对。遇到资料缺失先核实，遇到收费、诱导贷款或疑似盗用身份时保存证据。已发生损失可向当地人社部门投诉举报或向公安机关报案。涉及具体费用、劳动合同或资格规定时，读取当前主管部门公告再回答。
