# 投递前检查与防骗

## 每次投递检查

1. 招聘主体、岗位 ID、招聘类型和公告属于同一轮。
2. 官网或官方授权的 ATS 可查到同一项目和岗位。跳转域名、单位、届次一致。若经平台或中介发现，核对招聘类账号认证。经营性中介应能查到营业执照、人力资源服务许可证、收费标准和监督电话。
3. 毕业时间、学历、专业、国籍/工作资格、证书等硬性要求符合。偏好项单列。
4. 确认实际工作城市、面试地点、校招/实习性质、到岗时间及实习周期。
5. 截止日期、时区、志愿顺序及次数来自本轮官方公告。
6. 确认岗位所需证据、需要补问的信息和本人能说明的事实。
7. 用对应方向的简历，逐项对照网申中的学历、成绩、经历和时间。
8. 检查文件名、格式、大小、顺序及附件能否打开，删去样例占位符。
9. 使用本人可收信的渠道，确认手机号、邮箱和通知设置。仅在可信官方渠道填写必需字段。
10. 看清提交后是否能修改、能否重复投递和是否允许调剂。
11. 经历中的每个动作属于本人，每个数字有来源，团队结果与本人贡献分别写。
12. 确认测评和笔试截止、设备要求及官方登录方式。
13. 遇到收费、贷款、验证码、远程控制或陌生私链时暂停。
14. 由本人完成提交，保留确认页、提交时间、简历版本和下一步日期。

## 识别常见风险

| 信号 | 先做什么 |
| --- | --- |
| 报名费、押金、设备费或以保证金保留岗位 | 先不付款，通过用人单位官网复核 |
| 付费内推、央国企保录、保 Offer、保直签 | 回到官方流程，拒绝为面试名额、录用资格付费 |
| 面试被转成培训、分期或入职后扣费 | 分别核对招聘、培训和放款主体，现场不签培训或贷款合同 |
| 要充值、垫付订单、刷单或购买商品才能试岗 | 停止付款并保留聊天与转账证据 |
| 要短信验证码或银行卡密码 | 停止提供信息，已泄露时通过账号或银行官方渠道处理 |
| 要求共享屏幕、远程控制或在陌生流程做人脸认证 | 退出远程会话，通过官方招聘渠道复核 |
| 要求安装不明 App 或 APK | 回招聘方官网或正规应用商店核对应用及发布者 |
| 扣留身份证、毕业证等原件 | 核对出示要求，需交副本时可按实际用途标注 |
| 要向 HR 私人账户付款或代收转账 | 停止付款，向招聘方核实收款及用工主体 |
| 只用私人邮箱或社交账号发面试或录用信息 | 从企业官网核对域名、招聘电话或系统，避免点陌生私链 |
| 许诺高薪但没有对应的岗位门槛或职责 | 查薪酬口径、工作内容、合同和实际用人主体 |
| 职责模糊、空白合同或到岗再谈 | 要求可核实的 JD、办公地址和完整合同 |
| 要求立即赴异地参加封闭培训 | 暂停前往，和亲友确认行程，通过公开渠道核查培训地址和主体 |
| 催促当天签约或称不立即签就撤回 | 留出核对合同主体、报酬、社保和工作地点的时间 |
| 过度收集身份证、户口、家庭与财务信息 | 核对官方要求、使用目的和提交阶段，公开材料做脱敏 |

账号有认证只说明平台做过某种核对。遇到资料缺失先核实，遇到收费、诱导贷款或疑似盗用身份时保存证据。已发生损失可向当地人社部门投诉举报或向公安机关报案。涉及具体费用、劳动合同或资格规定时，读取当前主管部门公告再回答。
