# 官方招聘入口

这些入口用于发现机会。每次按毕业年月、城市、岗位和批次进入具体公告及网申。只看到入口时，记录它的用途，继续查当前岗位。

| 方向 | 起点 | 如何核验 |
| --- | --- | --- |
| 跨行业 | [国家大学生就业服务平台](https://www.ncss.cn/) · [国聘](https://www.iguopin.com/) | 先查活动或公司，再用招聘方公告确认届次及实际申请页。 |
| 互联网及制造 | [百度校招](https://talent.baidu.com/jobs/list) · [腾讯校招](https://join.qq.com/) · [中兴通讯](https://job.zte.com.cn/cn/campus-recruitment/Recruitment_positions/future.html) · [字节跳动校招](https://jobs.bytedance.com/campus) · [联想](https://talent.lenovo.com.cn/) · [华为](https://career.huawei.com/cn/campus-recruitment) | 先区分全职、暑期实习及日常实习，再找岗位 ID、工作地点和申请状态。 |
| 零售、运营、供应链 | [迪卡侬校园招聘](https://recruitment.decathlon.com.cn/p/campus.html) | 从官网进入同批校招系统，核对职位和城市。 |
| 央企、金融及综合职能 | [国航校招](https://zhaopin.airchina.com.cn/campus/) · [丝路基金招聘](https://www.silkroadfund.com.cn/cnweb/wzdt/jrwm/zpgg/index.html) · [证监会人才引进](https://www.csrc.gov.cn/csrc/c100082/common_list.shtml) | 从发布方找到当期公告及其网申链接。区分集团本部与分支机构，查看每个岗位的学历、专业及截止时间。 |

城市、专业或行业名单未覆盖时，用「单位全称 + 当前届次 + 校园招聘」找官方公告。再搜「单位全称 + 延期 / 补录 / 招聘结束」排查更新。政府就业专题或高校招聘会用于扩充搜索，仍要核对具体用人单位。
