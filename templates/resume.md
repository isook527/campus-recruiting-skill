# 三类可编辑简历模板

选择和当前 JD 最相关的一种，复制到自己的 Markdown 或文档。删去无事实支撑的模块，公开预览保留联系方式占位符。

## 互联网运营市场内容

- ［姓名］
- 求职方向：互联网运营 / 市场 / 内容｜［手机］｜［邮箱］｜［意向城市］
- 填写重点：用内容、用户、活动、调研或数据整理的真实动作证明岗位匹配。所有方括号内容都要替换；没有证据的模块可以删，不要硬凑。

### 教育背景

- 只保留真实课程、成绩和荣誉；不相关内容可删。
- 学校 / 专业 / 学历 / 时间：［学校］｜［专业］｜［本科/硕士］｜［20XX.09—20XX.06］

### 核心经历一

- 优先放最接近目标JD的一段，哪怕是课程项目。
- 经历名称 / 角色 / 时间：［项目］｜［本人角色］｜［时间］
- 经历要点：［动作＋对象＋方法＋可验证产出］［第二个本人动作；没有数字就不量化］

### 核心经历二

- 可选校园账号、社团公众号、活动、兼职或志愿服务。
- 经历名称 / 角色 / 时间：［经历］｜［角色］｜［时间］
- 经历要点：［选题/发布/反馈/现场执行等真实动作］［证据材料或可说明的结果］

### 工具与作品

- 只写实际使用过且能现场解释的工具。
- 工具：［Excel / PPT / 排版 / 问卷 / 数据工具——按本人事实填写］
- 作品链接：［去隐私后的作品集或附件链接；没有可删］

### 填写说明与真实性检查

- 先把目标JD拆成3项任务，再决定哪些经历放在第一页。
- 每条经历优先写：动作＋对象/任务＋方法＋可验证产出。
- 没有可靠数字时使用保守表达；不要用‘显著提升’替代证据。
- 课程、社团、兼职可以写，但要明确是课程/校园/兼职场景。
- 投递前朗读每一条；面试官追问三层仍能回答才保留。

### 本模板特别禁止

- 不要把浏览量、转化率、粉丝数写成自己的贡献，除非能说明来源和归因。
- 不要把校园账号写成商业增长项目。
- 不要写自己没用过的SQL、Python、数据平台或AI工具。
- 最后检查：每个动作是我本人做的吗？每个数字有来源吗？有没有把参与写成主导？删掉华丽词后仍然成立吗？

## 央国企银行综合

- ［姓名］
- 求职方向：央国企 / 银行综合职能｜［手机］｜［邮箱］｜［意向城市］
- 填写重点：突出规则意识、信息准确、事务跟进和材料交付，不靠空泛的‘稳定负责’。所有方括号内容都要替换；没有证据的模块可以删，不要硬凑。

### 教育背景

- 时间、学历和专业必须与网申一致。
- 学校 / 专业 / 学历 / 时间：［学校］｜［专业］｜［本科/硕士］｜［20XX.09—20XX.06］

### 实习 / 项目经历

- 优先放行政、财务支持、数据整理、项目跟进或服务经历。
- 单位 / 项目 / 角色 / 时间：［名称］｜［角色］｜［时间］
- 经历要点：［核对/整理/跟进/服务的具体对象和步骤］［可验证交付物；不确定结果标注待确认］

### 校园与志愿经历

- 用活动执行、签到、物资、信息统计证明基础动作。
- 经历名称 / 角色 / 时间：［经历］｜［角色］｜［时间］
- 经历要点：［本人负责范围］［遇到异常时的实际处理］

### 证书与技能

- 证书名称、成绩、有效期按原件填写。
- 语言 / 证书：［如实填写；没有就删］
- 办公工具：［只填实际会用并能现场演示的功能］

### 填写说明与真实性检查

- 先把目标JD拆成3项任务，再决定哪些经历放在第一页。
- 每条经历优先写：动作＋对象/任务＋方法＋可验证产出。
- 没有可靠数字时使用保守表达；不要用‘显著提升’替代证据。
- 课程、社团、兼职可以写，但要明确是课程/校园/兼职场景。
- 投递前朗读每一条；面试官追问三层仍能回答才保留。

### 本模板特别禁止

- 不要虚构政治面貌、奖项、排名、证书或实习证明。
- 不要把一次核对写成制度建设或风险管理。
- 不要把已截止公告继续写成当前可投。
- 最后检查：每个动作是我本人做的吗？每个数字有来源吗？有没有把参与写成主导？删掉华丽词后仍然成立吗？

## 人力行政项目支持

- ［姓名］
- 求职方向：人力 / 行政 / 项目支持｜［手机］｜［邮箱］｜［意向城市］
- 填写重点：把排期、文档、信息同步、面试安排、会议或物料等琐碎工作写清楚。所有方括号内容都要替换；没有证据的模块可以删，不要硬凑。

### 教育背景

### 支持类经历一

- 优先放能说明‘事情怎么被你跟到底’的一段。
- 单位 / 项目 / 角色 / 时间：［名称］｜［角色］｜［时间］
- 经历要点：［收集—整理—确认—提交/跟进的完整动作］［异常或临时变化时怎样处理］

### 支持类经历二

- 可用班委、课程展示、社团招新、志愿活动或兼职。
- 经历名称 / 角色 / 时间：［经历］｜［角色］｜［时间］
- 经历要点：［本人动作］［证据或边界：哪些不是本人负责］

### 工具与材料

- 工具不是越多越好，能说清实际用途更重要。
- 办公工具：［Word / Excel / PPT / 协作工具——按本人事实填写］
- 可展示材料：［排期表 / 会议纪要 / 文档 / 活动物料——先去隐私］

### 填写说明与真实性检查

- 先把目标JD拆成3项任务，再决定哪些经历放在第一页。
- 每条经历优先写：动作＋对象/任务＋方法＋可验证产出。
- 没有可靠数字时使用保守表达；不要用‘显著提升’替代证据。
- 课程、社团、兼职可以写，但要明确是课程/校园/兼职场景。
- 投递前朗读每一条；面试官追问三层仍能回答才保留。

- 不要把通知、催收或排版写成‘全面统筹’。
